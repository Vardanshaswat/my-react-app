# Portfolio

Recruiter-facing portfolio for a **3-year full-stack developer**. Layout is done. Replace placeholder copy with your details.

## Edit your profile

All personal content lives in one file:

```
src/content.js
```

Update name, headline, experience, projects, skills, email, GitHub, and LinkedIn there. The page title in `public/index.html` should match your name.

## Run locally

```bash
npm start
```

Opens [http://localhost:3000](http://localhost:3000).

## Deploy (GitHub Pages)

```bash
npm run deploy
```

Then in the GitHub repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch → `gh-pages` / `/ (root)`**.
